# Lesson 6 - JavaScript and TypeScript

This lesson project practices the JavaScript and TypeScript basics from class with a small React UI.

## Exercise focus

- Use TypeScript primitive types: `string`, `number`, and `boolean`.
- Define a typed object shape with `type LessonValue`.
- Use an `enum` for lesson status values.
- Practice comparison and logic operators with a score checker.
- Keep React state typed with `useState<number>`.

## Run locally

```bash
npm install
npm run dev
```
