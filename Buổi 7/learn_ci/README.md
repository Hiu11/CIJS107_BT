# Lesson 7 - Conditions and loops

This React + TypeScript exercise practices Lesson 7 concepts in a small interactive UI.

## Exercise focus

- Use `if`, `else if`, and `else` to choose weather advice.
- Use `switch-case` to convert weekday numbers to labels.
- Use a ternary operator for short conditional text.
- Use a `for...of` loop with `continue` to skip completed tasks.
- Use `break` to stop after collecting three unfinished tasks.

## Run locally

```bash
npm install
npm run dev
```
